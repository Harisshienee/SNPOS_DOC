Executive Summary

One Invisible Variable Is Limiting Every Sri Lankan Student

⚠ Problem

Nutrition is completely invisible in Sri Lanka's academic performance ecosystem. No school has any mechanism to observe, measure, or act on the relationship between what students eat and how they perform.

✦ Solution

SNPOS is a web-based dual-portal system connecting meal logs and academic grades through a Pearson correlation engine — built for Sri Lanka's food culture, 3G connectivity, and PDPA compliance.

📊 Evidence

Students score 12% higher in weeks with 5+ logged breakfasts [1]. Combined nutritional and academic risk triggers an automated teacher alert within 4 hours [2]. An 800+ item Sri Lanka Food Database is a first-of-its-kind national asset [3].

→ Action

Deploy SNPOS in Sri Lankan secondary schools beginning 2026. Every stakeholder gains measurable value. Every student is protected by privacy-first design. The system is ready.

Student Portal

Discussion · Resolution

SNPOS Augments Teacher Judgement — It Does Not Replace It

  • Correlations surface patterns; causation requires human interpretation — the Early Warning flag initiates a welfare conversation, not a clinical diagnosis
  • Confounding variables — socioeconomic status, sleep patterns, extracurricular load — are explicitly acknowledged and not controlled in Version 1.0
  • Ethical language design: 'Obese' is never displayed (replaced with 'Above Healthy Range'); scores are labelled 'Activity Scores' to prevent disordered comparisons
  • Individual meal logs remain private to students — teachers see only aggregated nutritional indicators, enforced at the API layer
Core Design Principle

Correlation ≠ Causation

The system shows what tends to happen together. The teacher decides what it means for this student, in this context, right now.

Privacy-by-Design
  • Meal logs — student-visible only
  • Teachers — aggregated indicators

  • All tiers enforced at API level

Limitations · Resolution

Five Known Constraints Strengthen Rather Than Weaken the Design

01
Prototype StageAcknowledged
Version 1.0 is a fully specified functional prototype — not yet deployed in a live school. Real-world usage data is not yet available to validate correlations at scale.
02
Correlation, Not CausationAcknowledged
Confounding variables — socioeconomic status, sleep patterns, extracurricular load — are not yet controlled in the Version 1.0 correlation model.
03
Self-Reported DataPlanned v2.0
Meal logging depends on honest student self-reporting. Anomaly detection for implausible entries is planned for Version 2.0 using ML-based pattern recognition.
04
Connectivity DependencyPlanned v1.3
Version 1.0 requires an active internet connection. Offline mode with automatic background sync for rural schools is planned for Version 1.3.
05
Food Database CompletenessOngoing
800+ items is a significant achievement, but cannot cover every regional variation, seasonal dish, or home-cooked item. Active curation continues post-launch.
